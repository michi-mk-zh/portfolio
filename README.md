# Portfolio – Michael Stefanoski

Persönliche Portfolio-Website, gebaut mit **React**, **JavaScript** und **Tailwind CSS** (Vite).

## Starten

```bash
npm install      # Pakete installieren (einmalig)
npm run dev      # Entwicklungsserver starten
```

Danach die angezeigte Adresse im Browser öffnen (meist http://localhost:5173).

## Veröffentlichen

```bash
npm run build    # erzeugt den Ordner dist/ mit der fertigen Seite
```

Den Inhalt von `dist/` kannst du bei einem Hoster wie GitHub Pages, Netlify oder Vercel hochladen.

## Inhalte ändern

Alle Texte, Projekte, Fähigkeiten und der Werdegang stehen in **`src/data.js`**.
Dort kannst du alles anpassen, ohne den restlichen Code anzufassen.
Dein Foto liegt unter `src/assets/profile.jpg` – einfach austauschen, um ein anderes Bild zu verwenden.
